# ARM SLEEF activation integration candidate

This external candidate replaces the ARM128 activation recipe with explicit SLEEF EXP/LOG operation order matching the pinned published warmed ARM JDK. The code is Boost-1.0 licensed. X86 arithmetic is unchanged. Native sigmoid/softplus and convolution use optional provider calls in all Qwen3.5 graph paths; unsupported width or library capability retains Java. Caller-owned array views do not extend the scratch or session lifetime.

The standalone numerical proof covered 878,137,347 comparisons, including all retained real inputs, with no mismatches. The v3 component comparison was faster than published in all four measured shapes with zero warm allocation, but standalone cold allocation failed and convolution precision remained unresolved. These results do not qualify this composed library. Later functional and Bonsai task-quality campaigns have completed for their exact artifacts, as recorded below. Load, first-request, latency, allocation, RSS, native-necessity and affected-model requirements remain separately unresolved; no component result qualifies every retained platform.

Raw prototypes and their failed controls are outside the repositories under `audit-artifacts/sleef-native-arm-v3` and `audit-artifacts/sleef-models-arm-v1`. No benchmark-only entry points or standalone library-loader lifecycle are included here.

Later completed evidence is enumerated in [the candidate inventory](bf16-swiglu-candidate-inventory.md#completed-later-functional-and-task-quality-evidence): Models tree `f3b32fbb` with core `e249e914` passed the 200-case ARM N2 Bonsai publisher comparison; the same Models tree with core `cc484b11` passed 77 native tests on each of six platforms, 16 original Bonsai fixture executions, and 1,029 real-model Java tests on each Linux architecture, all without skips. These are distinct artifact scopes. They do not validate the later `1ff05e11` forward-overlap repair, proposed Q8 cleanup, or any later composition, and they do not change this operation's UNPROVEN status.
